## 2 VGG家族

“Very Deep Convolutional Networks for Large-Scale Image Recognition” 是 VGG 模型的开山之作。核心贡献是==通过堆叠多个小尺寸（3x3）的卷积层来构建深度网络==，证明了==网络深度==对提升图像识别精度的关键作用。

这是列表的核心，展示了 VGG 家族的不同成员，数字代表网络的==深度==。

![[Pasted image 20260311144851.png|391]]

如果模型名字有：==_ bn==，例如，vgg16_bn，表示模型中加入了：Batch Normalization。bn 版本的模型通常收敛更快，性能略优或相当。

![[Pasted image 20260311145123.png|522]]

其中最常用的是VGG16和VGG19。

## 3 VGG16

`pretrained` 的意思是：

> **是否加载已经训练好的模型参数（预训练权重）**

```python
import torchvision  
  
vgg16_false = torchvision.models.vgg16(pretrained=False) #pretrained=False仅加载网络模型，无参数，有初始化参数  
  
vgg16_true = torchvision.models.vgg16(pretrained=True) #pretrained=True加载网络模型，并从网络中下载在数据集上训练好的参数，就是在数据集上表现好的参数。  
  
print(vgg16_true)
```

## 4 修改VGG网络（对1000类进行分类） 在网络最后添加一个线性层 在CIFAR10上（对10类）进行分类

这其实算是一种迁移学习——把一个模型在大数据集上学到的知识，迁移到新的任务上使用。

使用add_module()方法：

```python
import torchvision  
import torch.nn as nn  
vgg16_true = torchvision.models.vgg16(pretrained=True) #pretrained=True加载网络模型，并从网络中下载在数据集上训练好的参数  
dataset = torchvision.datasets.CIFAR10("../data",train= False, transform=torchvision.transforms.ToTensor(), download=True)  
vgg16_true.add_module('add_linear', nn.Linear(1000,10))  
print(vgg16_true)
```

==不添加层，仅修改vgg原有网络：==

```python
import torchvision  
import torch.nn as nn  
vgg16_true = torchvision.models.vgg16(pretrained=True) #pretrained=True加载网络模型，并从网络中下载在数据集上训练好的参数  
print("修改前",vgg16_true)  
dataset = torchvision.datasets.CIFAR10("../data",train= False, transform=torchvision.transforms.ToTensor(), download=True)  
vgg16_true.classifier[6] = nn.Linear(4096,10)  
print("修改后",vgg16_true)
```
