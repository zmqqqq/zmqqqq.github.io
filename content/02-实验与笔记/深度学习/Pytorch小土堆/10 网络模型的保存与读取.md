## 1 两种保存方式

### 1.1 torch.save(vgg16,"vgg16_method1.pth") 保存模型结构及模型参数

```python
import torch  
import torchvision  
  
vgg16 = torchvision.models.vgg16(weights=None)  
# 保存方式1  
torch.save(vgg16, "vgg16_method1.pth")
```

![[Pasted image 20260313083637.png]]

### 1.2 torch.save(vgg16.state_dict(),"vgg16_method2.pth") 仅保存模型参数存为字典，不保存模型结构（官方推荐）

```python
import torch  
import torchvision  
  
vgg16 = torchvision.models.vgg16(weights=None)  
# 保存方式1  
torch.save(vgg16, "vgg16_method1.pth")  
  
# 保存方式2,模型参数（官方推荐）
torch.save(vgg16.state_dict(),
torch.save(vgg16.state_dict(), "vgg16_method2.pth")
```

## 2 两种读取方式

==按照保存方式1进行读取，读到的是完整的模型结构和参数：==

```python
import torch  
  
# 方式1-》保存方式1,加载模型  
model1 = torch.load("vgg16_method1.pth",weights_only=False)  
print(model1)
```

==按照保存方式2进行读取，读到的只有参数：==

```
import torch  

# 方式2 加载模型  
model2 = torch.load("vgg16_method2.pth")  
print(model2)
```

## 4 方式1 torch.load(“vgg16_method1.pth”)存在的问题

==保存模型+参数:==

```python
import torch
from torch import nn

class Tudui(nn.Module):
	def __init__(self):
		super(Tudui, self).__init__()
		self.conv1 = nn.Conv2d(3, 64, kernel_size=3)

def forward(self, x):
	x = self.conv1(x)
	return x

tudui = Tudui()
torch.save(tudui, "tudui_method1.pth")
```

==读取模型及参数：==

```python
import torch

model = torch.load("tudui_method1.pth")
print(model)
```

![[Pasted image 20260313091752.png]]

==解决方法：①要么在读取的文件中把模型的定义复制过来：

```python
import torch  
import torchvision  
from torch import nn  

class Tudui(nn.Module):  
    def __init__(self):  
        super(Tudui, self).__init__()  
        self.conv1 = nn.Conv2d(in_channels=3, out_channels=64,kernel_size=3)  
  
    def forward(self, input):  
        output = self.conv1(input)  
        return output  
# 这里不需要重新定义tudui = Tudui()
  
model = torch.load("tudui_method1.pth",weights_only=False)  
print(model)
```
