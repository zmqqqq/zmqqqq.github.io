> [!abstract]- 非线性激活层的作用
> 非线性激活函数（Activation Function）的主要作用是：
> 
> 1. **引入非线性**：如果网络中只有线性变换，多层网络仍然等价于单层线性模型。
> 
> 2. **提升模型表达能力**：可以拟合复杂函数关系，而不仅仅是线性关系。
> 
> 3. **使深层网络有效** ：多层网络通过激活函数组合，可以表示复杂的函数映射。

## 1 ReLU

![[Pasted image 20260310122453.png]]

==inplace== 参数含义：为True时对原输入进行激活函数的计算，计算结果赋给原输入；为False时，返回对原输入进行激活函数的计算的结果，原输入不发生改变，保留原始数据，默认为False。`可以理解为是否覆盖input`。

```python
import torch  
from torch import nn  
from torch.nn import ReLU  
  
input = torch.tensor([[1, -0.5],  
                      [-1, 3]])  
print("reshape前",input.shape)  
input = torch.reshape(input,(-1,1,2,2)) # batchsize自己算，一维，2*2  
print("reshape后",input.shape)  
  
class Tudui(nn.Module):  
    def __init__(self):  
        super(Tudui, self).__init__()  
        self.relu1 = nn.ReLU()  
  
    def forward(self, input):  
        output = self.relu1(input)  
        return output  
  
tudui = Tudui()  
output = tudui(input)  
print("RuLU后",output)
```

## 2 Sigmoid

![[Pasted image 20260310123144.png]]

```python
import torch  
import torchvision  
from torch import nn  
from torch.nn import ReLU  
from torch.nn import Sigmoid  
from torch.utils.data import DataLoader  
from torch.utils.tensorboard import SummaryWriter  
  
input = torch.tensor([[1, -0.5],  
                      [-1, 3]])  
print("reshape前",input.shape)  
input = torch.reshape(input,(-1,1,2,2)) # batchsize自己算，一维，2*2  
print("reshape后",input.shape)  
  
dataset = torchvision.datasets.CIFAR10("../data",train=False,download=True,  
                                       transform=torchvision.transforms.ToTensor())  
dataloader = DataLoader(dataset=dataset,batch_size=64)  
  
class Tudui(nn.Module):  
    def __init__(self):  
        super(Tudui, self).__init__()  
        self.relu1 = nn.ReLU()  
        self.sigmoid1 = nn.Sigmoid()  
  
    def forward(self, input):  
        output = self.sigmoid1(input)  
        return output  
  
tudui = Tudui()  
  
step = 0  
writer = SummaryWriter("../relu")  
for data in dataloader:  
    imgs, targets = data  
    writer.add_images("input",imgs,step)  
    output = tudui(imgs)  
    writer.add_images("output",output,step)  
    step += 1  
writer.close()
```
