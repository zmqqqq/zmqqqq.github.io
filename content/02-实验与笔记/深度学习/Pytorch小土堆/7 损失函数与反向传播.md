## 1 Loss Functions


> [!example]- Loss Functions注意项
> loss function的使用应根据需求，选定好损失函数后，按损失函数要求的维度（形状）输入
> 1. 根据需求去选择损失函数
> 2. 一定要注意输入和输出的形状要求


损失函数（Loss Function）是深度学习模型训练的核心 —— 它==量化模型预测值（Prediction）与真实标签（Target）的差异，指导模型通过反向传播更新参数，最终让预测逼近真实值==。PyTorch 在 torch.nn 模块中封装了几乎所有常用损失函数，且均继承自 nn.Module ，可像网络层一样灵活使用。

![[Pasted image 20260310205330.png|376]]
![[Pasted image 20260310210056.png|534]]


> [!example]- 常见的Loss Functions
> 1. nn.L1Loss ：计算输入与目标之间的平均绝对误差（MAE）。
> 2. nn.MSELoss ：计算输入与目标之间的均方误差（平方L2范数）。
> 3. nn.CrossEntropyLoss ：计算输入logits（模型原始输出）与目标之间的交叉熵损失。
> 4. nn.CTCLoss ：连接主义时序分类损失，适用于无需对齐长度的时序序列数据。
> 5. nn.NLLLoss ：计算负对数似然损失，需配合 LogSoftmax 使用。
> 6. nn.PoissonNLLLoss ：基于泊松分布的负对数似然损失。
> 7. nn.GaussianNLLLoss ：基于高斯分布的负对数似然损失。
> 8. nn.KLDivLoss ：计算KL散度（相对熵），衡量两个概率分布的差异。
> 9. nn.BCELoss ：计算目标与输入概率之间的二元交叉熵。

### 1.1 nn.L1Loss

nn.L1Loss ：计算输入与目标之间的平均绝对误差（MAE）。

![[Pasted image 20260310210509.png|649]]

**输入和输出维度要求：**

![[Pasted image 20260310210514.png|618]]
![[Pasted image 20260310210536.png]]

```python
import torch  
from torch.nn import L1Loss  
  
inputs = torch.tensor([1,2,3], dtype=torch.float32)  
targets = torch.tensor([1,2,5], dtype=torch.float32)  
  
inputs = torch.reshape(inputs,(1,1,1,3)) # 1行3列  
targets = torch.reshape(targets,(1,1,1,3)) # 1行3列  
  
loss = L1Loss()  
result = loss(inputs,targets)  
print(result)  
  
loss2 = L1Loss(reduction='sum')  # 注意，reduction默认为mean
result2 = loss2(inputs,targets)  
print(result2)
```

### 1.2 nn.MSELoss

nn.MSELoss ：计算输入与目标之间的均方误差（平方L2范数）。

import torch

inputs = torch.tensor([1,2,3], dtype=torch.float32)  
targets = torch.tensor([1,2,5], dtype=torch.float32)  
  
inputs = torch.reshape(inputs,(1,1,1,3)) # 1行3列

### 1.3 nn.CrossEntropyLoss

nn.CrossEntropyLoss ：计算输入logits（模型原始输出）与目标之间的交叉熵损失。

交叉熵损失函数（Cross-Entropy Loss Function）是在==分类问题==中经常使用的一种损失函数，特别是在多分类问题中。它==衡量了模型输出的概率分布与真实标签之间的差异，通过最小化交叉熵损失来调整模型参数，使得模型更好地适应分类任务。==

交叉熵损失（Cross-Entropy Loss）是深度学习中多分类任务的核心损失函数，核心作用是衡量「模型预测的概率分布」与「真实标签的概率分布」之间的差异，差异越小则模型预测越准确。

## 2 使用前面搭建的网络结合CrossEntropyLoss计算损失

```python
import torch  
import torchvision  
from torch import nn  
from torch.utils.data import DataLoader  
from torch.nn import Conv2d,MaxPool2d, Flatten, Linear, Sequential  
  
dataset = torchvision.datasets.CIFAR10("../data",train=False,download=True,  
                                    transform=torchvision.transforms.ToTensor())  
dataloader = DataLoader(dataset=dataset,batch_size=1)  
  
class Tudui(nn.Module):  
    def __init__(self):  
        super(Tudui, self).__init__()  
        self.model1 = Sequential(  
            Conv2d(in_channels=3, out_channels=32, kernel_size=5, stride=1, padding=2),  
            MaxPool2d(kernel_size=2),  
            Conv2d(in_channels=32, out_channels=32, kernel_size=5, stride=1, padding=2),  
            MaxPool2d(kernel_size=2),  
            Conv2d(in_channels=32, out_channels=64, kernel_size=5, stride=1, padding=2),  
            MaxPool2d(kernel_size=2),  
            Flatten(),  
            Linear(in_features=1024, out_features=64),  
            Linear(in_features=64, out_features=10)  
        )  
  
    def forward(self, x):  
        x = self.model1(x)  
        return x  
  
loss = nn.CrossEntropyLoss()  
tudui = Tudui()  
for data in dataloader:  
    imgs, targets = data  
    output = tudui(imgs)  
    # print("output", output)  
    # print("targets", targets)    result_loss = loss(output, targets)  
    print(result_loss)
```

## 3 反向传播

张量梯度的属性：grad

自动求导（Autograd）： 在张量上进行操作时，PyTorch 会自动跟踪操作并构建计算图，可以使用 .backward() 方法（反向传播）计算梯度，然后通过 .grad 属性获取梯度值。

在pycharm中对该行打断点，可以看到具体的梯度值。

```python
import torch  
import torchvision  
from torch import nn  
from torch.utils.data import DataLoader  
from torch.nn import Conv2d,MaxPool2d, Flatten, Linear, Sequential  
  
dataset = torchvision.datasets.CIFAR10("../data",train=False,download=True,  
                                    transform=torchvision.transforms.ToTensor())  
dataloader = DataLoader(dataset=dataset,batch_size=1)  
  
class Tudui(nn.Module):  
    def __init__(self):  
        super(Tudui, self).__init__()  
        self.model1 = Sequential(  
            Conv2d(in_channels=3, out_channels=32, kernel_size=5, stride=1, padding=2),  
            MaxPool2d(kernel_size=2),  
            Conv2d(in_channels=32, out_channels=32, kernel_size=5, stride=1, padding=2),  
            MaxPool2d(kernel_size=2),  
            Conv2d(in_channels=32, out_channels=64, kernel_size=5, stride=1, padding=2),  
            MaxPool2d(kernel_size=2),  
            Flatten(),  
            Linear(in_features=1024, out_features=64),  
            Linear(in_features=64, out_features=10)  
        )  
  
    def forward(self, x):  
        x = self.model1(x)  
        return x  
  
loss = nn.CrossEntropyLoss()  
tudui = Tudui()  
for data in dataloader:  
    imgs, targets = data  
    output = tudui(imgs)  
    result_loss = loss(output, targets)  
    result_loss.backward()  
    print("ok")
```
