## 5.1 特征缩放（Feature Scaling）

### 特征缩放定义

**目的：** 将不同取值范围的`特征缩放`到相近的数值范围内，以加快梯度下降的收敛速度。

![[Pasted image 20260203205611.png]]

面对`多维度特征问题`，我们需要保证这些特征具有相近的尺度，帮助梯度下降算法更快地收敛。

以房价问题为例，假设仅用两个特征，`房屋的尺寸`和`数量`，以两个参数分别为横纵坐标，假设尺寸在0-2000平方英尺，数量在0-5之间。

绘制代价函数的等高线图能，看出图像会显得很扁，梯度下降算法需要非常多次的迭代才能收敛。

解决办法：将所有的特征的尺度尽量缩放到-1到1之间，令：

![[Pasted image 20260203205937.png]]

**为什么要特征缩放？**

上图的两个特征，我们可以看到，

如果`不缩放`：梯度下降走的是“又长又窄”的椭圆，更新参数会**左右来回震荡**，收敛非常慢；

如果`缩放`：成本函数的等高线更接近**圆形**，梯度下降可以**更直地走向最低点**。

### 特征缩放的各种分类

**①最大值缩放**

用特征值除以该特征的最大值，使特征缩放到 [0,1] 或 [−1,1] 附近。

所有特征值都在 **[0, 1]** 之间（如果原数据非负），最简单、计算最快。

优点：简单直观，适合所有值 ≥ 0 的特征；

缺点：对异常值敏感，不保证均值在 0 附近。

![[Pasted image 20260203211116.png]]


![[Pasted image 20260203210606.png]]

**②均值归一化**

定义：先减去均值，再除以取值范围，使特征分布以 0 为中心。

![[Pasted image 20260203211254.png]]

特征值大致在 **[-1, 1]** 之间，均值为 0。

优点：分布以 0 为中心，非常适合梯度下降；

缺点：仍然对极端异常值敏感。



![[Pasted image 20260203210933.png]]

**③Z-score归一化**

定义：通过减去均值、再除以标准差，把特征转换为**均值为 0、方差为 1**的分布。

## 5.2 检查梯度下降是否收敛

![[Pasted image 20260203212108.png]]

梯度下降法的任务是找到参数w和b，希望能够最小化代价函数J。

**①图像法**

我们经常画出代价函数的图像。绘制每次迭代时的J的值。横轴是迭代次数。

这条曲线也成为**学习曲线**。

如果梯度下降法正常工作的话，那么代价函数的值应该是越来越小的。

如果随着迭代法的进行，代价函数的值变大了那就是`学习率α太大`了。

![[Pasted image 20260203212837.png]]

由上图，当迭代次数达到300次时，代价函数J开始趋于平稳，曲线已经趋于平稳了。这就意味着已经收敛了，曲线不再下降了。

**②自动收敛测试**

- 首先，令 ε（“epsilon”，表示一个极小的阈值）为10^-3（即0.001）。
- 然后规定收敛条件：如果代价函数J在一次迭代中，减少的量小于或等于ε，就宣布（算法）收敛。
- 括号里补充说明：此时找到的参数w（权重向量）和b（偏置），已经接近代价函数的全局最小值。

## 5.3 学习率的选择

如果学习率太小，它会运行得非常慢。如果学习率过大，它可能不会收敛。
