# 6 单调队列！！！

==**经典模板题**：滑动窗口内，快速求最大/小值。时间O(n)。==

![[Pasted image 20260525194147.png]]

当前窗口的左边界是i-k+1。

求最小值的时候，队列里只保留那些**有可能成为最小值的下标**。

如果一个数比新来的数大，而且它还更早过期，那它以后永远不可能当最小值，所以删掉。

求最大值同理，只保留那些**有可能成为最大值的下标**。

![[Pasted image 20260526100910.png]]

开始的是维护单调递增队列，只要出现队尾的比当前的大，就删队尾。用来求最小值。

后面维护的是单调递减队列，只要出现队尾的比当前元素小，就删队尾。用来求最大值。

```c++
#include<bits/stdc++.h>
using namespace std;

const int N = 100010;

// son是对应结点的子结点,
// cnt是当前这个点结尾的单词有多少个
// idx当前用到了哪个下标
int son[N][26], cnt[N], idx; // 下标是0的点，既是根结点，又是空结点
char str[N];

void insert(char str[]){
    int p = 0;
    // 在C++里，字符串结尾是'\0',所以可以拿str[i]判断有没有走到结尾
    for(int i=0; str[i]; i++){
        int u = str[i] - 'a'; // 将26个字母映射为0-25
        if(!son[p][u]) son[p][u] = ++ idx;
        p = son[p][u];
    }
    
    cnt[p]++; // 以p结尾的单词数量多了一个
}

int query(char str[]){
    int p = 0;
    for(int i=0;str[i];i++){
        int u = str[i]-'a';
        if(!son[p][u]) return 0;
        p = son[p][u];
    }
    return cnt[p];
}

int main(){
    int n;
    cin>>n;
    while(n--){
        char op;
        cin>>op>>str;
        // cout<<op<<str<<endl;
        if(op=='I') insert(str);
        else cout<<query(str)<<endl;
    }
}
```

# 9 并查集

==用来干嘛的？==

（1）将两个集合合并；（2）询问两个元素是否在一个集合当中。

==基本原理==

每个集合用一棵树来表示。树根的编号就是整个集合的编号。

每个结点存储它的父结点，p【x】表示x的父结点。

**问题1：** 如何判断一个点是否是树根？**if(p【x】== x)**

**问题2：** 如何求x的树根编号？**while(p【x】 != x) x=p【x】**（找树根）

**问题3：** 如何合并两个集合？**px是x的集合编号，py是y的集合编号。p【x】=y**（加一条边）

![[Pasted image 20260402101852.png]]

==本质== **记find函数！！！**

## 合并集合

==面试非常容易出的题目==

![[Pasted image 20260402095821.png|633]]

```c++
#include<bits/stdc++.h>
using namespace std;

const int N = 100010;
int p[N];

int find(int x){ // 返回x的祖宗结点 + 路径压缩
    if(p[x]!=x) p[x] = find(p[x]);
    return p[x];
}

int main(){
    int n,m;
    cin>>n>>m;
    for(int i=1;i<=n;i++) p[i]=i;
    
    while(m--){
        char op;
        int a,b;
        cin>>op>>a>>b;
        
        if(op=='M') p[find(a)]=find(b);
        
        else{
            if(find(a)==find(b)) cout<<"Yes"<<endl;
            else cout<<"No"<<endl;
        }
        
    }
}
```

## 连通块中点的数量

![[Pasted image 20260402134423.png|474]]

```c++
#include<bits/stdc++.h>
using namespace std;

const int N = 100010;
int p[N], sizee[N]; // 每一个集合里点的数量,初始为1

int find(int x){ // 返回x的祖宗结点 + 路径压缩
    if(p[x]!=x) p[x] = find(p[x]);
    return p[x];
}

int main(){
    int n,m;
    cin>>n>>m;
    for(int i=1;i<=n;i++){
        p[i] = i;
        sizee[i] = 1;
    }
    
    while(m--){
        string op;
        int a,b;
        cin>>op;
        
        if(op=="C"){
            cin>>a>>b;
            if(find(a)==find(b)) continue;
            sizee[find(b)]+=sizee[find(a)];
            p[find(a)]=find(b);
        }
        
        else if(op=="Q1"){
            cin>>a>>b;
            if(find(a)==find(b)) cout<<"Yes"<<endl;
            else cout<<"No"<<endl;
        }
        else{
            cin>>a;
            cout<<sizee[find(a)]<<endl;
        }
    }
}
```

## 堆排序

![[Pasted image 20260402144309.png|323]]

==数组模拟写法：==

```c++
#include<bits/stdc++.h>

using namespace std;

const int N = 100010;

int heap[N], sizee; // sizee存的是当前heap堆有多少个元素

void down(int u){
    int t=u; // t表示三个点里的最小值(结点和对应两个子结点)
    if(u*2<=sizee && heap[u*2]<heap[t]) t=u*2;
    if(u*2+1<=sizee && heap[u*2+1]<heap[t]) t=u*2+1;
    if(u!=t){
        swap(heap[t],heap[u]);
        down(t);
    }
}

int main(){
    int n,m;
    cin>>n>>m;
    for(int i=1;i<=n;i++) cin>>heap[i];
    sizee = n;
    
    for(int i=n/2;i;i--) down(i);
    
    while(m--){
        cout<<heap[1]<<" ";;
        heap[1]=heap[sizee--];
        down(1);
    }
}
```

### vector

==常用函数：==

| 函数           | 作用                   |
| ------------ | -------------------- |
| size()       | 返回元素个数               |
| empty()      | 判断是否为空（空 = 1，非空 = 0） |
| clear()      | 清空所有元素               |
| front()      | 获取**第一个元素**          |
| back()       | 获取**最后一个元素**         |
| push_back(x) | 尾部添加元素 x             |
| pop_back()   | 删除最后一个元素             |

==两个关键迭代器:==

- `begin()`：指向**第一个元素**的指针
- `end()`：指向**最后一个元素的下一个位置**的指针
    
    （排序、遍历等算法常用，比如 `sort(b.begin(), b.end())`）

### queue

队列。

push--向队尾插入一个元素；front--返回队头元素；back--返回队尾元素；pop--弹出队头元素。

有size、empty函数，queue、priority_queue、stack没有clear函数。

### priority_queue

优先队列，其实就是堆。

push--向堆中插入一个元素；top返回堆顶元素；pop弹出堆顶元素。

一般定义的堆默认是==大根堆==。

==大根堆、小根堆定义：==

### stack

栈和我们队列基本差不多。

push--向栈顶插入元素；top--返回栈顶元素；pop--弹出栈顶元素。

empty、size都有，时间复杂度为O(1)，没有clear函数。

![[Pasted image 20260525140020.png|480]]


### deque

双端队列，加强版vector。

size、empty、clear都有。

front--返回第一个元素；back--返回最后一个元素；push_back--向最后插入一个元素；pop_back--弹出最后一个元素；push_front--向队首插入一个元素；pop_front--从队首弹出一个元素。

支持begin和end迭代器。

deque效率非常低。。。
