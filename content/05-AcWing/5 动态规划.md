## 0 分数背包问题

==思路：==

（1）每个物品可以**取一部分**；

（2）按 **价值密度（w/v）从大到小排序**；

（3）能装就装，装不下就装一部分。

==结构体+排序+贪心：==

![[Pasted image 20260409092052.png]]

```c++
#include<bits/stdc++.h>
using namespace std;

struct Bag{
    double v; // 体积
    double w; // 价值
};
// 按单位价值排序
bool cmp(Bag a,Bag b){
    return (double)a.w / a.v >(double)b.w / b.v; // 降序排,想升序就<
}

int main(){
    int N,V;
    cin>>N>>V;
    
    Bag bag[1010];
    
    for(int i=1;i<=N;i++) cin>>bag[i].v>>bag[i].w;
    
    double ans = 0;
    
    sort(bag+1,bag+N+1,cmp); //[左闭,右开) bag+1指向bag[1]
    
    for(int i=1;i<=N;i++){
        if(V>=bag[i].v){
            // 全拿 
            V-=bag[i].v;
            ans+=bag[i].w;
        }else{
            // 拿一部分
            ans+=bag[i].w/bag[i].v * V;
            V=0;
            break;
        }
    }
    cout<<ans<<endl;
}
```

## 1 01背包问题

==N个物品，容量为V的背包。每件物品有体积vi和价值wi。在背包能装得下的前提下，最大价值是多少?==

==特点：== 每件物品最多用一次，要么0次要么1次。

![[Pasted image 20260409095527.png|346]]

![[Pasted image 20260409100032.png|626]]

==f(i, j) = 在“只考虑前 i 个物品”的前提下背包容量不超过 j 时的最大价值。==本质是子问题的最优解。我们要的最终答案是f(N, V)，即**所有物品 + 完整容量**的最优解。

注意，`f(i, j)` 不仅仅是一个数字，它是**某个集合的某种属性**：f(i, j) = 考虑前 i 个物品，容量 ≤ j 的所有方案集合 的 某个属性。

常见属性有：

| 属性类型 | 举个栗子🌰             |
| ---- | ------------------ |
| 最大值  | 01背包的最大价值、完全背包最大价值 |
| 最小值  | 最少硬币数（零钱问题）        |
| 数量   | 装满背包的方案数           |
| 是否可达 | 背包能否正好装满           |

- 关键词：
	- 前 i 个物品（范围限制）
	- 容量 ≤ j（条件限制）

![[Pasted image 20260409101126.png|560]]

### 01背包朴素版本

![[Pasted image 20260409102154.png|568]]

```c++
#include<bits/stdc++.h>
using namespace std;

const int N = 1010;

int n,m; // 物品个数 容量
int v[N],w[N];
int f[N][N]; // 状态

int main(){
    cin>>n>>m;
    for(int i=1;i<=n;i++) cin>>v[i]>>w[i];
    
    // f[0][0~m]初始化0,全局定义了默认就是0不用管啦~
    for(int i=1;i<=n;i++){
        for(int j=0;j<=m;j++){
            f[i][j]=f[i-1][j];
            if(j>=v[i]) f[i][j]=max(f[i][j],f[i-1][j-v[i]]+w[i]);
        }
    }
    cout<<f[n][m]<<endl;
}
```

### 01背包的一维滚动数组优化版本

![[Pasted image 20260409104908.png|523]]

```c++
#include<bits/stdc++.h>
using namespace std;

const int N = 1010;

int n,m; // 物品个数 容量
int v[N],w[N];
int f[N]; // f[j] 表示容量为 j 的背包能装的最大价值

int main(){
    cin>>n>>m;
    for(int i=1;i<=n;i++) cin>>v[i]>>w[i];
    
    for(int i=1;i<=n;i++){ // 枚举物品
        for(int j=m;j>=v[i];j--){ // 逆序枚举容量
            f[j]=max(f[j],f[j-v[i]]+w[i]);
        }
    }
    cout<<f[m]<<endl;
}
```

```c++
#include<bits/stdc++.h>
using namespace std;

const int N = 1010;

int n,m; // 物品个数 容量
int v[N],w[N];
int f[N][N]; // 状态

int main(){
    cin>>n>>m;
    for(int i=1;i<=n;i++) cin>>v[i]>>w[i];
    
    for(int i=1;i<=n;i++)
        for(int j=0;j<=m;j++)
            for(int k=0;k*v[i]<=j;k++){
                f[i][j]=max(f[i][j],f[i-1][j-k*v[i]]+w[i]*k);
            }
    cout<<f[n][m]<<endl;
}
```

## 3 多重背包

==特点：== 每个物品最多有si个。（这里我们会讲到一个经典优化版）

==本题数据范围比较小：==

![[Pasted image 20260409125400.png|537]]

### 多重背包暴力写法

其实就是完全背包朴素版的变形：

![[Pasted image 20260409130817.png]]

```c++
#include<bits/stdc++.h>
using namespace std;

const int N = 110;
int n,m;
int v[N],w[N],s[N];
int f[N][N];

int main(){
    cin>>n>>m;
    for(int i=1;i<=n;i++) cin>>v[i]>>w[i]>>s[i];
    
    for(int i=1;i<=n;i++)
        for(int j=0;j<=m;j++){
            for(int k=0;k<=s[i] && j>=k*v[i];k++){
                f[i][j]=max(f[i][j],f[i-1][j-v[i]*k]+w[i]*k);
            }
        }
    cout<<f[n][m]<<endl;
}
```
