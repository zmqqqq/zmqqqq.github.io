Neural Networks（神经网络）的基本灵感来源于`人脑的神经系统`。大脑由数十亿个神经元相互连接而成，形成一个庞大的网络。当一个神经元接收到来自其他神经元的足够强的信号时，它就会被“激活”，并向下一个神经元发送信号。

人工神经网络（ANN）就是试图用数学模型来模拟这个过程的简化版本。

## 8.1 神经元和大脑（Neurons and the brain）

![[Pasted image 20260205165459.png]]

首先，我们来看一下大脑中的基本单位——生物神经元是如何工作的：

1. 树突：像树枝一样的分支，负责接收来自其他神经元的信号。
2. 细胞体：处理接收到的信号。
3. 轴突：一根长长的“导线”，负责传输处理后的电信号。
4. 突触：轴突末端与另一个神经元树突连接的点。它并非物理连接，而是一个微小的间隙，通过释放化学物质（神经递质）来传递信号。**突触的强度（即传递信号的效率）是可变的，这是学习和记忆的物理基础。**

当一个神经元从它的树突接收到足够多的兴奋性信号（超过某个阈值），它就会产生一个电脉冲（称为“动作电位”），并通过轴突传递下去。这个过程可以简化为：`接收输入 -> 整合处理 -> 决定是否输出`。

![[Pasted image 20260205170046.png]]

人工神经网络是对这个生物过程的极度简化和数学抽象。它们的对应关系如下：

| 生物神经系统  | 人工神经网络    | 功能                  |
| ------- | --------- | ------------------- |
| 神经元     | 人工神经元/节点  | 基本计算单元              |
| 树突      | 输入连接 & 权重 | 接收输入信号，并赋予其重要性      |
| 突触强度    | 权重        | 连接的重要性，可调节（学习的核心）   |
| 细胞体整合信号 | 加权求和 + 偏置 | 整合所有输入信号            |
| 动作电位阈值  | 激活函数      | 决定神经元是否应该被“激活”及输出强度 |
| 轴突      | 输出连接      | 将输出信号传递给下一个神经元      |

## 8.2 需求预测（Demand Prediction）

是不是畅销品？输入价格等其他信息，然后输出成为畅销品的概率。

![[Pasted image 20260205201244.png]]

输入层有一个特征向量（四个特征），然后它被输入到隐藏层，我们将用一个向量来表示这个隐藏层输出的激活向量。然后输出层将这三个激活值作为输入并输出一个数字，这将是神经网络的最终激活或最终预测。

![[Pasted image 20260205201810.png]]

我们把一些最原始的信息（比如价格、运费、营销、材料）交给神经网络，网络中间会自己“想办法”把这些信息组合成一些更抽象、更有意义的判断（比如这个东西贵不贵、有没有名气、质量看起来好不好），最后再根据这些综合判断，给出一个结果——比如“这个产品成为畅销品的概率有多大”。  我们不需要提前告诉机器什么是“性价比”或“质量”，神经网络会在训练过程中自己学会这些中间概念。

遮住左边的部分，剩下的就是一个逻辑回归算法或者逻辑回归单元。

因此思考这个神经网络的一种方式就是`逻辑回归`。但它是一个可以学习自己特征的逻辑回归版本，使得更容易做出准确的预测。

## 8.3 示例：图像识别

在图像识别问题中，**输入是一张图片**。

假设这是一张 **1000 × 1000 像素**的灰度图像，那么在计算机里，它可以表示成一个 **1000 × 1000 的矩阵**，矩阵中的每一个元素对应一个像素的**亮度值**。

每个像素的亮度值通常在 **0～255** 之间，例如左上角像素的亮度可能是 **197**。

为了把图片作为神经网络的输入，我们会按照一定的顺序（比如从左到右、从上到下），把这个 **1000 × 1000 的矩阵“展开”成一个列向量**。

这样，输入向量就包含了 **1,000,000 个数字**，每一个数字代表一个像素的亮度。

在人脸识别任务中，我们要做的事情就是：  

**训练一个神经网络，输入是这一百万个像素亮度值组成的特征向量，输出是图片中人物的身份**。 通过大量训练数据，神经网络会学会如何从这些原始像素中提取有用的信息，从而完成识别任务。

![[Pasted image 20260205202950.png]]

输入的图像x首先被送入**第一层隐藏层**。这一层的神经元会从原始像素中提取一些**初级特征**。  
第一层隐藏层的输出再传递给**第二个隐藏层**，第二个隐藏层在此基础上组合并提取**更高层次的特征**。  
随后，这些结果继续传入**第三个隐藏层**，不断形成更加抽象的表示。  
最后，最顶层的表示被送入**输出层**，输出一个概率，用来估计输入图像属于某个特定人的可能性。

![[Pasted image 20260205203226.png]]

在**第一个隐藏层**中，每个神经元只关注图像中的一个**很小的区域**，它们通常学会检测一些非常简单的特征，比如**垂直线、斜线或某个方向的边缘**。这些神经元并不“知道”这是人脸，只是在判断某个小区域里是否存在特定方向的亮暗变化。

到了**第二个隐藏层**，神经元会把第一层检测到的许多**短小的边缘和线段组合起来**，从而形成更有意义的结构。例如，有些神经元可能学会检测**眼睛的大致形状**，有些可能对**鼻子的某个角度或鼻子的底部**特别敏感。图中那些小方框，就是这些神经元所学到特征的可视化表示。

在**第三个隐藏层**中，神经元开始进一步聚合这些面部局部特征，把眼睛、鼻子、嘴巴等组合在一起，尝试检测**更完整、更粗略的面部结构**。这一层不再关注单个边缘或局部，而是在判断“这整体看起来像不像一张脸”。

通过这样一层一层的特征提取，网络最终形成了一组**高度抽象、对身份区分非常有用的特征表示**。这些特征被送入输出层，用来估计图像中是否是某个特定的人。
