## 1 Pytorch环境的配置与安装

[【超详细教程】2025年3月最新Pytorch安装教程（同时讲解安装CPU和GPU版本)](https://blog.csdn.net/Mr_Chp/article/details/146641434?fromshare=blogdetail&sharetype=blogdetail&sharerId=146641434&sharerefer=PC&sharesource=2301_80098008&sharefrom=from_link)

**Anaconda** ：是一个集成了 Python、环境管理器和包管理器的工具平台，用来创建和管理独立的 Python 环境；package 是实现具体功能的代码库（如 numpy、torch），由 Anaconda（conda）或 pip 安装并在环境中使用。

**CUDA**（Compute Unified Device Architecture）是 NVIDIA 提供的一种让程序使用显卡（GPU）进行并行计算的技术平台。（CUDA 就是让深度学习、矩阵运算这些“算得特别多”的任务，从 CPU 转移到 NVIDIA 显卡上加速计算的工具。）

**🕳常见坑：盲目安装 CUDA：**

很多安装教程会直接让人先安装 CUDA，但往往并没有解释什么是 CUDA，也不说明是否真的有必要。事实上，CUDA 的安装过程比较繁琐，而且对初学者来说很容易踩坑。  
**对于使用 PyTorch 的大多数场景，只要电脑有 NVIDIA 显卡并且显卡驱动正常，通常不需要单独安装 CUDA Toolkit，因为 PyTorch 已经自带所需的 CUDA 运行库。**

查看显卡：

```bash
nvidia-smi
```

只有在电脑有 NVIDIA 显卡并且驱动正常的情况下，才能安装并使用 CUDA 版本的 PyTorch；否则只能使用 CPU 版本。

如果检测到 **CUDA 可用**：

```python
torch.cuda.is_available()  # True
```

创建环境：

```bash
conda create -n pytorch python=3.9
```

激活环境：

```bash
conda activate pytorch
```

退出环境：

```bash
conda deactivate
```

## 3 Python学习中的两大法宝函数（也可以用在PyTorch）

### 3.1 理解Package结构及法宝函数的作用

一个 package（pytorch） 就像一个工具箱。这个工具箱里面有四个分割区域，每个分割区域也有不同的小的工具箱。比如3分区里面就有不同的a，b，c三种不同的工具。

- dir() 函数：能让我们知道工具箱以及工具箱中的分隔区有什么东西（打开，看见）
- help() 函数：能让我们知道每个工具是如何使用的，工具的使用方法（说明书）

![[Pasted image 20260206163430.png]]

### 3.2 实践操作

打开Pycharm，输入：

```python
import torch
dir(torch)
```

可以看到输出了大量的分隔区（或理解为更小的工具箱），ctrl+F找到cuda：

![[Pasted image 20260206163929.png]]

看cuda分隔区里有什么，输入

```python
dir(torch.cuda)
```

可以看到又输出了大量的分隔区

![[Pasted image 20260206164123.png]]

继续输入：

```python
dir(torch.cuda.is_available)
```

可以看到输出的前后都带有双下划线__，这是一种规范，说明这个变量不容许篡改，即它不再是一个分隔区，而是一个确确实实的函数（相当于工具，可以用help()函数）

![[Pasted image 20260206164247.png]]

对工具使用 help()：

```python
help(torch.cuda.is_available)
```

**注意 is_available 不带括号**

![[Pasted image 20260206164346.png]]

它这个函数是怎么用的：返回一个布尔值（True或False），表明cuda是否可用。

### 如何在Jupyter中新建项目？

激活环境：

```bash
conda activate [your env name]
```

![[Pasted image 20260206165833.png]]

`① 直接在命令行输入 Jupyter Notebook`

那么 Jupyter Notebook 会在**当前命令行所在目录**启动。通常情况下，默认目录是 **C 盘的系统目录或用户目录**。

`②在指定目录下启动（更常用）`

如果你的 `.ipynb` 文件不在 C 盘，而是在 **D 盘或 E 盘**，建议先切换到对应目录，再启动 Jupyter Notebook。

1）切换同一磁盘下的目录（D切D）

```bash
cd D:\Documents
```

2）切换到其他磁盘（两种方式）

方式一：先切换盘符，再切目录

```bash
E:
cd E:\temp\node
```

方式二：一次完成（使用 `/d` 参数）

```bash
cd /d E:\temp\node
```

`③ 启动 Jupyter Notebook`

```bash
jupyter notebook
```

此时打开的 Jupyter Notebook：根目录就是你刚刚切换到的目录，新建或打开的 `.ipynb` 文件都会在这里。
