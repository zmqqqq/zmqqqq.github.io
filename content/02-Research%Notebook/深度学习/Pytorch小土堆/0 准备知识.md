## 1 Pytorch环境的配置与安装

[【超详细教程】2025年3月最新Pytorch安装教程（同时讲解安装CPU和GPU版本)](https://blog.csdn.net/Mr_Chp/article/details/146641434?fromshare=blogdetail&sharetype=blogdetail&sharerId=146641434&sharerefer=PC&sharesource=2301_80098008&sharefrom=from_link)

**Anaconda** ：是一个集成了 Python、环境管理器和包管理器的工具平台，用来创建和管理独立的 Python 环境；package 是实现具体功能的代码库（如 numpy、torch），由 Anaconda（conda）或 pip 安装并在环境中使用。

**CUDA**（Compute Unified Device Architecture）是 NVIDIA 提供的一种让程序使用显卡（GPU）进行并行计算的技术平台。（CUDA 就是让深度学习、矩阵运算这些“算得特别多”的任务，从 CPU 转移到 NVIDIA 显卡上加速计算的工具。）

**🕳常见坑：盲目安装 CUDA：**

很多安装教程会直接让人先安装 CUDA，但往往并没有解释什么是 CUDA，也不说明是否真的有必要。事实上，CUDA 的安装过程比较繁琐，而且对初学者来说很容易踩坑。  
**对于使用 PyTorch 的大多数场景，只要电脑有 NVIDIA 显卡并且显卡驱动正常，通常不需要单独安装 CUDA Toolkit，因为 PyTorch 已经自带所需的 CUDA 运行库。**

查看显卡：

```bash
nvidia-smi
```

只有在电脑有 NVIDIA 显卡并且驱动正常的情况下，才能安装并使用 CUDA 版本的 PyTorch；否则只能使用 CPU 版本。

如果检测到 **CUDA 可用**：

```python
torch.cuda.is_available()  # True
```

```bash

```

激活环境：

```bash

```

退出环境：

```bash

```

## 3 Python学习中的两大法宝函数（也可以用在PyTorch）

### 3.1 理解Package结构及法宝函数的作用

一个 package（pytorch） 就像一个工具箱。这个工具箱里面有四个分割区域，每个分割区域也有不同的小的工具箱。比如3分区里面就有不同的a，b，c三种不同的工具。

- dir() 函数：能让我们知道工具箱以及工具箱中的分隔区有什么东西（打开，看见）
- help() 函数：能让我们知道每个工具是如何使用的，工具的使用方法（说明书）

`③ 启动 Jupyter Notebook`

```bash

```

此时打开的 Jupyter Notebook：根目录就是你刚刚切换到的目录，新建或打开的 `.ipynb` 文件都会在这里。

### 5.1 Dataset & Dataloader

PyTorch 读取数据涉及两个类：Dataset & Dataloader

**Dataset**：提供一种方式，获取其中需要的数据及其对应的真实的 label 值，并完成编号。主要实现以下两个功能：

- 如何获取每一个数据及其label
- 告诉我们总共有多少的数据

**Dataloader**：打包（batch_size），为后面的神经网络提供不同的数据形式。

```python
from torch.utils.data import Dataset  
from PIL import Image   # 读取图片  
import os   # 想要获得所有图片的地址，需要导入os（系统库）  
  
class MyData(Dataset):  
    def __init__(self,root_dir,label_dir):  # 创建初始化类，即根据这个类去创建一个实例时需要运行的函数  
        # 通过索引获取图片的地址，需要先创建图片地址的list  
        # self可以把其指定的变量给后面的函数使用，相当于为整个class提供全局变量  
        self.root_dir = root_dir  
        self.label_dir = label_dir  
        self.path = os.path.join(self.root_dir,self.label_dir)  
        self.img_path = os.listdir(self.path)   # 获得图片下所有的地址  
  
    def __getitem__(self, idx): # idx为编号  
        # 获取每一个图片  
        img_name = self.img_path[idx]  # 名称  
        img_item_path = os.path.join(self.root_dir, self.label_dir, img_name)  # 每张图片的相对路径  
        img = Image.open(img_item_path) # 读取图片  
        label = self.label_dir  
        return img,label  
  
    def __len__(self):  # 数据集的长度  
        return len(self.img_path)  
  
# 用类创建实例  
root_dir = "dataset/train"  
ants_label_dir = "ants"  
bees_label_dir = "bees"  
ants_dataset = MyData(root_dir, ants_label_dir)  
bees_dataset = MyData(root_dir, bees_label_dir)  
img, label = ants_dataset[0]  
img.show() # 可视化第一张图片  
img, label = bees_dataset[0]  
img.show() # 可视化第一张图片  
# 将ants(124张)和bees(121张)两个数据集进行拼接  
train_dataset = ants_dataset + bees_dataset
```
