最大池化层 保留输入的特征，同时减少数据量加快训练速度。

- 参数
	- ==kernel_size==:池化窗口大小
		- 可以是整数（如 3 ）或元组（如 (2, 3) ）
		- 元组表示在高度和宽度方向上的池化区域
	- ==stride==：滑动步长
		- 默认值 = kernel_size
		- 控制窗口每次移动的距离
	- ==padding==：填充
		- 在输入周围添加负无穷大的填充
		- 这样最大值操作不会受填充值影响
	- ==dilation==：膨胀率，也叫做==空洞卷积==
		- 控制窗口中元素之间的间距
		- dilation=1：正常相邻元素
		- dilation=2：元素间间隔1个位置
	- ==return_indices==：是否返回最大值位置
		- 为 True 时会返回最大值的位置索引
		- 用于后续的 MaxUnpool2d 反池化操作
	- ==ceil_mode==：尺寸计算模式
		- False ：向下取整（floor）
		- True ：向上取整（ceil）

```python
import torch  
from torch import nn  
from torch.nn import MaxPool2d  
  
input = torch.tensor([[1,2,0,3,1],  
                      [0,1,2,3,1],  
                      [1,2,1,0,0],  
                      [5,2,3,1,1],  
                      [2,1,0,1,1]])  
  
input = torch.reshape(input, (-1,1,5,5)) # 把原来的 [5,5] 的矩阵变成 [B,C,H,W] 的格式。  
# -1 表示：这一维让 PyTorch 自动计算  
  
print(input.shape) # torch.Size([1, 1, 5, 5])  
  
  
class Tudui(nn.Module):  
    def __init__(self):  
        super(Tudui, self).__init__()  
        self.maxpool1 = nn.MaxPool2d(kernel_size=3, ceil_mode=True)  
  
    def forward(self, input):  
        output = self.maxpool1(input)  
        return output  
  
tudui = Tudui()  
output = tudui(input)  
print(output)
```

```python
import torch  
import torchvision  
from torch import nn  
from torch.nn import MaxPool2d  
from torch.utils.data import DataLoader  
from torch.utils.tensorboard import SummaryWriter  
  
dataset = torchvision.datasets.CIFAR10("../data",train=False,download=True,  
                                       transform=torchvision.transforms.ToTensor())  
dataloader = DataLoader(dataset,batch_size=64)  
  
class Tudui(nn.Module):  
    def __init__(self):  
        super(Tudui, self).__init__()  
        self.maxpool1 = nn.MaxPool2d(kernel_size=3, ceil_mode=False)  
  
    def forward(self, input):  
        output = self.maxpool1(input)  
        return output  
  
tudui = Tudui()  
  
writer = SummaryWriter("../logs_maxpool")  
step = 0  
for data in dataloader:  
    imgs, targets = data  
    writer.add_images("input",imgs,step)  
    output = tudui(imgs)  
    writer.add_images("output",output,step)  
    step += 1  
  
writer.close()
```

==为什么需要池化？==

1. 降低计算量
2. 提取更重要的特征（MaxPool 会保留：区域里最强的特征，而忽略小的变化）
3. 增强平移不变性（如果目标稍微移动：猫向左移动一点，池化后的特征不会变化太大。这对识别很重要。）
