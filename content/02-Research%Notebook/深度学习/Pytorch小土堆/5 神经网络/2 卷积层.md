![[Pasted image 20260224153815.png]]

注意，输入和卷积的尺寸没有达到如下要求：

我们需要进行尺寸的变换：

![[Pasted image 20260224154105.png]]

```python
import torch  
import torch.nn.functional as F  
  
input = torch.tensor([[1,2,0,3,1],  
                      [0,1,2,3,1],  
                      [1,2,1,0,0],  
                      [5,2,3,1,1],  
                      [2,1,0,1,1]])  
  
kernel = torch.tensor([[1,2,1],  
                       [0,1,0],  
                       [2,1,0]])  
  
input = torch.reshape(input,(1,1,5,5)) # 1个batchsize，1个通道  
kernel = torch.reshape(kernel,(1,1,3,3))  
  
print(input.shape, kernel.shape)  
  
output = F.conv2d(input,kernel,stride=1)  
print(output)
```

## 2 nn.Conv2d参数详解

nn.Conv2d 是用于处理二维数据（如图像）的卷积层。它是卷积神经网络中最重要的组成部分之一，主要用于从输入数据中提取特征，例如图像的边缘、纹理、形状等。

```python
nn.Conv2d(
	in_channels, # 输入通道数
	out_channels, # 输出通道数（卷积核数量）
	kernel_size, # 卷积核大小
	stride=1, # 步长
	padding=0, # 填充
	dilation=1, # 空洞卷积
	groups=1, # 分组卷积
	bias=True # 偏置项
)
```

==input-输入张量==

- 形状要求: (minibatch, in_channels, iH, iW)
	- minibatch : 批量大小
	- in_channels : 输入通道数
	- iH: 输入高度
	- iW: 输入宽度

==weight - 卷积核权重==

- 形状要求: (out_channels, in_channels/groups, kH, kW)
	- out_channels : 输出通道数
	- in_channels/groups : 每个卷积核的输入通道数
	- kH : 卷积核高度
	- kW : 卷积核宽度

==bias - 偏置项（可选）==

- 形状要求: (out_channels,)
	- 必须与输出通道数匹配
	- 可以为 None （无偏置）

==stride - 步长==

- 类型: int 或 tuple
	- 单个数字：同时在高度和宽度方向使用相同步长
	- 元组： (stride_height, stride_width)

==padding - 填充==

- 类型: int , tuple , 或 str
	- int : 四周均匀填充
	- tuple : (padding_height, padding_width)
	- str : 'valid' （无填充）或 'same' （保持输入输出尺寸相同）
