```python
import torch  
import torch.nn.functional as F  
  
input = torch.tensor([[1,2,0,3,1],  
                      [0,1,2,3,1],  
                      [1,2,1,0,0],  
                      [5,2,3,1,1],  
                      [2,1,0,1,1]])  
  
kernel = torch.tensor([[1,2,1],  
                       [0,1,0],  
                       [2,1,0]])  
  
input = torch.reshape(input,(1,1,5,5)) # 1个batchsize，1个通道  
kernel = torch.reshape(kernel,(1,1,3,3))  
  
print(input.shape, kernel.shape)  
  
output = F.conv2d(input,kernel,stride=1)  
print(output)
```

## 2 nn.Conv2d参数详解

nn.Conv2d 是用于处理二维数据（如图像）的卷积层。它是卷积神经网络中最重要的组成部分之一，主要用于从输入数据中提取特征，例如图像的边缘、纹理、形状等。

```python
nn.Conv2d(
	in_channels, # 输入通道数
	out_channels, # 输出通道数（卷积核数量）
	kernel_size, # 卷积核大小
	stride=1, # 步长
	padding=0, # 填充
	
	# 重点关注以上五个参数即可
	
	dilation=1, # 空洞卷积
	groups=1, # 分组卷积
	bias=True # 偏置项
)
```

==input-输入张量==

- 形状要求: (minibatch, in_channels, iH, iW)
	- minibatch : 批量大小
	- in_channels : 输入通道数
	- iH: 输入高度
	- iW: 输入宽度

==weight - 卷积核权重==

- 形状要求: (out_channels, in_channels/groups, kH, kW)
	- out_channels : 输出通道数
	- in_channels/groups : 每个卷积核的输入通道数
	- kH : 卷积核高度
	- kW : 卷积核宽度

==bias - 偏置项（可选）==

- 形状要求: (out_channels,)
	- 必须与输出通道数匹配
	- 可以为 None （无偏置）

==stride - 步长==

- 类型: int 或 tuple
	- 单个数字：同时在高度和宽度方向使用相同步长
	- 元组： (stride_height, stride_width)

==padding - 填充==

- 类型: int , tuple , 或 str
	- int : 四周均匀填充
	- tuple : (padding_height, padding_width)
	- str : 'valid' （无填充）或 'same' （保持输入输出尺寸相同）

==接下来我们拿一批图片 → 送进卷积层 → 看看卷积前后图片形状怎么变：==

```python
import torch  
import torchvision  
from torch import nn  
from torch.nn import Conv2d  
from torch.utils.data import DataLoader  
from torch.utils.tensorboard import SummaryWriter  
  
dataset = torchvision.datasets.CIFAR10("../data", train=False, transform=torchvision.transforms.ToTensor(),  
                                       download=True)  
dataloader=DataLoader(dataset, batch_size=64)  
  
# 搭建网络  
class Tudui(nn.Module):  
    def __init__(self):  
        super(Tudui, self).__init__()  
        self.conv1 = nn.Conv2d(in_channels=3,out_channels=6,kernel_size=3,stride=1,padding=0)  
  
    def forward(self, x):  
        x = self.conv1(x)  
        return x  
  
# 初始化网络  
tudui = Tudui()  
print(tudui)  
  
writer = SummaryWriter("../logs")   # 日志文件存储位置  
step = 0  
for data in dataloader:  
    imgs, targets = data  
    output = tudui(imgs)  
    print("原图像的形状",imgs.shape)  
    print("卷积之后图像的形状",output.shape)  
    # torch.Size([64, 3, 32, 32])  
    writer.add_images("input",imgs,step)  
    # 卷积之后图像的形状 torch.Size([64, 6, 30, 30])是6个通道的 而add_images只能接收3通道的输入  
    # torch.Size([64, 6, 30, 30]) -> [xxx,3,30,30]  
    output = torch.reshape(output,(-1,3,30,30)) # 不严谨操作 ---对output进行reshape 增大batchsize的数量 减少通道数  
    writer.add_images("output",output,step)  
    step += 1  
  
writer.close()
```
